============================================================
  ChronoCare – IoT alapú egészségügyi monitoring rendszer
  Páll László – Szakdolgozat, Nyíregyházi Egyetem, 2025
============================================================

FEJLESZTŐKÖRNYEZET
------------------
  Java verzió  : Java 17 LTS
  Keretrendszer: Spring Boot 3.4.5
  Build eszköz : Apache Maven 3.x
  IDE          : IntelliJ IDEA (Ultimate ajánlott)
  Adatbázis    : H2 (fájlalapú, beágyazott)
  MQTT broker  : HiveMQ publikus broker (ssl://broker.hivemq.com:8883)
  IoT szimulátor: Wokwi (ESP32 online szimulátor)

RENDSZERKÖVETELMÉNYEK
---------------------
  - Java 17 vagy újabb (https://adoptium.net/)
  - Apache Maven 3.8 vagy újabb
  - Internetkapcsolat (MQTT broker eléréshez)

PROJEKT MEGNYITÁSA
------------------
  1. Töltse le vagy csomagolja ki a projektet.
  2. Nyissa meg IntelliJ IDEA-ban:
       File → Open → válassza a projekt gyökérmappáját (pom.xml-t tartalmazó mappa)
  3. Maven automatikusan letölti a függőségeket.

LOKÁLIS FUTTATÁS
----------------
  Parancssorból (Maven segítségével):

    cd chronocare
    mvn spring-boot:run

  Vagy IntelliJ IDEA-ból:
    Futtassa a ChronoCareApplication.java főosztályt.

  Az alkalmazás elindul a következő címen:
    http://localhost:8080

ALAPÉRTELMEZETT BELÉPÉSI ADATOK
--------------------------------
  Az adatbázis az első indításkor automatikusan feltöltődik mintaadatokkal.

  Orvos fiókok:
    Felhasználónév: house    Jelszó: admin   (Dr. House)
    Felhasználónév: strange  Jelszó: admin   (Dr. Strange)

  Páciens fiókok:
    Felhasználónév: janos    Jelszó: 1234    (Teszt János, 65 év)
    Felhasználónév: maria    Jelszó: 1234    (Minta Mária, 42 év)

  Új páciens regisztrálható a főoldalon keresztül is.

H2 ADATBÁZIS KONZOL (fejlesztői)
---------------------------------
  Cím  : http://localhost:8080/h2-console
  JDBC : jdbc:h2:file:./data/chronodb
  User : sa
  Jelszó: (üres)

MQTT KAPCSOLAT
--------------
  A rendszer TLS titkosított MQTT kapcsolatot használ:
    Broker : ssl://broker.hivemq.com:8883
    Topic  : patient/{patientId}/measurements
    QoS    : 1

  Az IoT szimulátort (Wokwi ESP32) a GitHub repository
  /wokwi mappájában található sketch.ino fájl tartalmazza.
  Wokwi szimulátor: https://wokwi.com

ADATBÁZIS INICIALIZÁLÁS (localhost kiváltás)
---------------------------------------------
  A H2 fájlalapú adatbázis automatikusan létrejön az első
  indításkor a ./data/chronodb útvonalon. Nem szükséges
  külön adatbázisszerver telepítése.

  Ha friss adatbázissal szeretne indítani, törölje a
  ./data/ mappát, majd indítsa újra az alkalmazást.
